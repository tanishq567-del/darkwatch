# DarkWatch Terms of Use

DarkWatch is a demonstration project intended for defensive cybersecurity learning and simulated brand-monitoring activities.

## Permitted Use

- Testing against the fictional sample data included in this project.
- Learning about keyword matching, queue processing, sanitization and application architecture.
- Demonstrating defensive threat intelligence concepts in a controlled environment.

## Prohibited Use

- Using the software to access, download, distribute or trade illegal content.
- Attempting to access systems or websites without permission.
- Collecting, storing or sharing personal information or credentials without authorization.
- Using the project to facilitate cybercrime, harassment or unauthorized surveillance.

## Limitations

This demonstration does not scan the Tor network or real dark-web websites.

Sample findings are fictional and are not evidence of an actual security incident.

Use of this project must comply with applicable laws, policies and authorization requirements.
